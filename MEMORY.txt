--------------------------------------------------------------------------------
  WHAT IS THIS APP
--------------------------------------------------------------------------------
MusicWidgets is a native macOS app that lets users put beautiful, aesthetic
music-themed widgets on their desktop. The widgets show what's currently playing
(song title, artist, album art) by reading local now-playing info from Spotify
or Apple Music — no login, no API keys, no internet required for core features.

The app was born from a viral TikTok moment with the original VinylWidget,
which got a lot of hype and proved there's demand for this kind of product.

The VinylWidget was built by Andre + partner over multiple sessions. It is a
mature, working, production-quality codebase. MusicWidgets is the evolution
of that project into a proper multi-widget app store product.

--------------------------------------------------------------------------------
  BUSINESS MODEL
--------------------------------------------------------------------------------
- Sold on the Mac App Store
- One-time purchase (NOT a subscription — lifetime access)
- Price TBD but targeting the €4–€10 range
- Free to download, all widgets locked behind a one-time in-app purchase (IAP)
- No free widget tier — everything is behind the unlock
- Future: maybe iOS/iPad version if Mac version does well

IMPORTANT strategic note from VinylWidget memory:
- Do NOT promise full Spotify queue integration without platform approval.
  Spotify local scripting gives current-track metadata but NOT a real queue.
- Apple Music local scripting is richer but still not official "Up Next".
- Position the core product honestly as "local mode" — it's still very compelling.
- Spotify OAuth connected mode exists in VinylWidget but is limited/beta.
- First paying user = signal to invest in Apple Developer account (€99/yr).

--------------------------------------------------------------------------------
  APP STRUCTURE
--------------------------------------------------------------------------------
Full macOS dock app (shows in dock, has its own window — not menu bar only).

SCREENS:
  1. Home / Gallery
     - Header: "MusicWidgets" title + settings gear icon
     - Category cards (Vinyl / CD Players / Cassettes) with icons
     - Row list below showing all categories with descriptions
     - Light, airy Apple-like UI — liquid glass / skeuomorphism aesthetic
     - Accent colors: Vinyl=Blue #5A7AFF, CD=Green #34C47C, Cassette=Orange #FF7A40

  2. Category Library (drill-down)
     - Reached by tapping a category card
     - Grid of widget styles for that category
     - Each card shows a preview + name + unlock button
     - Slide-in animation from right, back button slides back

  3. Active Widget (floating on desktop)
     - When user picks a widget, it floats on the desktop via NSPanel
     - Desktop-level only — NOT above fullscreen apps (CGWindowLevelForKey desktopIconWindow + 1)
     - Only one widget active at a time
     - Appears on all Spaces (collectionBehavior: canJoinAllSpaces, stationary)
     - Draggable by window background (isMovableByWindowBackground = true)

--------------------------------------------------------------------------------
  DESIGN DIRECTION
--------------------------------------------------------------------------------
- Apple-native aesthetic — feels like it could have been made by Apple
- Light UI base for the gallery app (soft grey-blue gradient)
- Liquid glass cards — white translucent frosted glass feel
- Skeuomorphic widget previews (the actual widgets look like real physical objects)
- Rounded corners everywhere, generous spacing, subtle shadows
- Hover animations (scale up 1.02–1.05), spring transitions
- Widget previews: dark backgrounds with gradient, the actual widget renders inside

--------------------------------------------------------------------------------
  TECH STACK
--------------------------------------------------------------------------------
- Language: Swift
- UI framework: SwiftUI (AppKit for window management + NSPanel)
- Now-playing: AppleScript polling every 0.25s (very responsive)
  - Spotify: reads track/artist/album/artworkURL/playback state/position/duration
  - Apple Music: writes album art to temp file, reads all metadata
  - Smart source selection: plays vs paused, recency of state change
- Album art: URL from Spotify, temp file from Apple Music
- Color extraction: extracts dominant palette from album art (ColourExtractor)
- AI themes: Groq API (llama-3.3-70b-versatile), free, no credit card
  - Generates JSON theme spec from user text prompt
  - Style modes: flat / gradient / wild
- Target: macOS 14.0+
- Xcode 26.3

--------------------------------------------------------------------------------
  KEY LESSONS FROM VINYLWIDGET BUILD
--------------------------------------------------------------------------------
1. Animation sequencing is HARD — use deterministic phase-based state machines,
   not implicit transitions. Loose animations cause ghosts and visual artifacts.

2. AppleScript polling works great at 0.25s intervals. Don't go faster.
   Run it on a background DispatchQueue, publish results on main.

3. Album art from Apple Music: must write binary to temp file, then read path.
   Spotify gives you a URL directly — much simpler.

4. NSPanel window setup: GENERATE_INFOPLIST_FILE = NO, set INFOPLIST_FILE manually.
   Critical for URL schemes and any custom Info.plist keys.

5. Flat gradient bug: when padding color arrays to required count, always repeat
   the last color (result.last), never fall back to a default palette.

6. Spotify OAuth callback: register BOTH app(_:open:) AND kAEGetURL Apple Event
   handler — the URL can arrive via either path depending on macOS version.

7. Queue from Spotify without Web API = not trustworthy. Be honest about limitations.
   Apple Music local = best-effort heuristic only.

8. AI theme generation: text→JSON approach is perfect. Don't try AI→image directly.
   Use Groq (free, no credit card, 14,400 req/day).

9. Working tree discipline: keep branches clean, tag releases. Don't commit secrets.

10. Onboarding: if closed before completion, terminate the app.
    UserDefaults key for completion: onboarding.completed.v1

  CRITICAL GOTCHAS LEARNED:
  1. Music sync needs entitlements + Info.plist:
     - MusicWidgets.entitlements: com.apple.security.automation.apple-events = true
     - Info.plist: NSAppleEventsUsageDescription string
     - CODE_SIGN_ENTITLEMENTS build setting must point to the .entitlements file
     Without these, AppleScript polling silently fails (no music sync).
  2. Song-switch ANIMATION needs the AnimationOverlayWindow (defined inside
     VinylWidgetView.swift). The flying disk/sleeves render in that separate
     unclipped NSPanel that floats just above the widget. AppDelegate MUST create
     it AND subscribe to animator.$phase to show/position/hide it. A widget-only
     AppDelegate makes the animation look broken (disk just vanishes).
  3. AnimationOverlayWindow level = desktopIconWindow + 2 (widget is + 1).
